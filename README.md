# File Storage Application
![Project Logo](frontend/public/logo/logo-128.png)

The application consists of a React app for the Frontend UI, A Typescript Serverless REST API and
various AWS microservices such as S3, Cognito, Secrets Manager and Cloudfront.


[Live demo here](https://daqw40bwe9v16.cloudfront.net)

## Please Note
Email auto verification has been enabled when signing up via the Cognito hosted UI as to not require anyone to share personal emails when logging into this application. Any valid email address can be used to sign up with (e.g email@gmail.com)

## Getting Started
To get started running the aplication locally run the below commands
```bash
npm install

cd frontend

npm run start:local
```
